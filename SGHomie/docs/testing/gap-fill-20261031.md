# Test gap fill — 31 October 2026

This follow-up adds local coverage for several gaps listed in the earlier testing report. It does not replace that report's dated ML evidence or claim browser, hosted-service, or production acceptance.

## Added and corrected coverage

- `profile-workflows.test.mjs`: initial profile setup success/failure, safe creation of a missing profile, and profile edit persistence.
- `seller-dashboard.test.mjs`: submit gating, invalid postal-code rejection, verified address lookup, owner-bound listing create/edit, and delete-confirmation cancellation.
- `access-control.test.sql`: bucket visibility and size configuration plus seller/admin Storage RLS for upload, metadata access, update, and delete paths.
- `admin-dashboard.test.mjs`: non-admin dashboard denial before privileged data loads, listing approval/rejection/deletion, enquiry response handling, and user-directory display.
- `auth-context-profile-dedupe.test.mjs`: a delayed profile result from a prior account cannot grant the newly signed-in account stale roles.
- `enquiry-behavior.test.mjs`: a history refresh failure after a successful insert no longer reports that the enquiry submission failed or invites a duplicate submission.
- Corrected the two stale assertions recorded in the earlier report: the auth confirmation button uses the current “Go to Sign In” label, and Explore flat-size filters use listing text rather than bedroom counts.
